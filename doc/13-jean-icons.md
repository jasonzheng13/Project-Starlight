Replaced the six authored SVG approximations with Jean's game icon artwork on
September 24, 2026, at the user's request. Retrieved from the image links on
[Genshin.gg's Jean page](https://genshin.gg/characters/jean/).

Source URLs follow `https://sunderarmor.com/GENSHIN/Skill/1/Jean/constellation_N.png`,
where `N` is 1 through 6. Files are retained without image edits. Artwork belongs
to Genshin Impact's rights holders; the mirror is not a grant of reuse rights.

`MemoryEmblem` chooses the image by row index. CSS owns the surrounding medallion
and interaction glow. Empty alt text avoids repeating decorative content because
each memory button already has an accessible name. The six files total less than
9 KB, so they are served locally without an image transformation request.
